1.What is the difference between var, let, and const?
Answer:The difference between var, let, and const:
     1.var is function-scoped and can be redeclared and updated.
     2.let is block-scoped and can be updated but not redeclared in the same scope.
     3.const is block-scoped and cannot be reassigned after declaration.

2.What is the spread operator (...)?
Answer:The spread operator (...) is used to expand elements of an array or properties of an object into another array or object.

3.What is the difference between map(), filter(), and forEach()?
Answer:The difference between map(), filter(), and forEach():
    1.map() creates a new array by transforming each element.
    2.filter() creates a new array containing only elements that satisfy a condition.
    3.forEach() executes a function for each element but does not return a new array.

4.What is an arrow function?
Answer:An arrow function is a shorter way to write a function in JavaScript.

5.What are template literals?
Answer:Template literals are strings enclosed in backticks (`) that allow embedded expressions using ${} and support multi-line strings.
